# Literature Selection Notes

The automated OpenAlex pass returned 300 candidates and 36 policy-eligible records, but most used a Corsi score only as an auxiliary measure. Manual review retained four open-access papers with at least 100 OpenAlex citations.

- `W2133111582` is the canonical computerized protocol source. It directly specifies the nine-block display, forward/backward recall, progressive span procedure, visual response acknowledgement, practice, and presentation timing.
- `W2024648041` and `W1972939642` support the spatial-attention and visuospatial-memory interpretation.
- `W2165302691` satisfies the high-impact-journal requirement for the broader spatial working-memory construct. Its different task state machine is explicitly excluded from implementation decisions.

Citation counts were checked on 2026-07-12. Protocol decisions are not taken from papers that merely report a Corsi score without describing administration.
