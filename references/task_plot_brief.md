# Task Plot Brief

Title: Corsi Block-Tapping Task

Construct: visuospatial short-term memory / working memory

## Rows

- Forward: reproduce the highlighted blocks in the same serial order.
- Backward: reproduce the highlighted blocks in reverse serial order.

## Shared Visual Facts

- The participant screen is black with nine identical yellow square outlines in a fixed irregular layout.
- Sequence ready shows only the nine idle outlines for 500 ms.
- Each encoded location fills yellow for 500 ms; the board returns to outlines for 500 ms between highlights, producing a 1000 ms onset-to-onset interval.
- A small blue circle appears in the upper-right with the final highlight and remains during recall.
- Recall is self-paced up to 30 s. The participant clicks exactly as many blocks as were highlighted; each clicked block briefly fills yellow.
- Practice alone shows correct or incorrect feedback for 750 ms. Scored trials proceed directly to a 500 ms blank interval.
- Scored span starts at length 2, uses two attempts at each length, advances after at least one correct attempt, and stops after two failures or successful length 9.

## Representative Timeline

- Forward: Idle board (500 ms) -> three yellow highlights shown sequentially (500 ms each; 500 ms gaps) -> blue ready marker -> click the same locations in order (30 s max) -> practice feedback only (750 ms) -> blank (500 ms).
- Backward: Idle board (500 ms) -> three yellow highlights shown sequentially (500 ms each; 500 ms gaps) -> blue ready marker -> click the same locations in reverse order (30 s max) -> practice feedback only (750 ms) -> blank (500 ms).
